# Журнал публикаций

Эта ветка — реестр публикаций тестового стенда. Значащий файл один:
`published.json` — версия схемы и массив записей, по одной на публикацию.
Записи опознают опубликованные байты парой `buildId` + `digest`; `digest` —
авторитетная идентичность содержимого, идентификатор развёртывания — только след.

## Правило append-only

Прежние записи не изменяются, не удаляются и не переставляются; новые
добавляются только в конец; версия схемы не меняется. Проверка этого свойства
выполняется заданием журнала и падает закрыто при любом расхождении.

Правила защиты ветки запрещают удаление и non-fast-forward, но они защищают
историю коммитов, а не содержимое файла, поэтому проверка содержимого нужна
отдельно и реализуется в задании журнала.
