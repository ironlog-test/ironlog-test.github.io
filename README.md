# IronLog — тестовый стенд

Публичный стенд для проверки сборок IronLog на отдельном origin, не затрагивая
production и облако.

- Тестовый сайт: https://ironlog-test.github.io/
- Источник кода: https://github.com/tmksdm/IronLog (публичный).
- Ветка источника для публикации: `test-deploy`.

## Назначение

Стенд собирает и публикует **тестовую** сборку IronLog (`npm run build:test`,
режим Vite `testdeploy`) и позволяет проверить её в браузере телефона владельца
до того, как изменения попадут в основную линию.

## Что здесь принципиально отсутствует

- **Production-данные.** Тестовая сборка не содержит учётных данных Supabase:
  облачные модули заменены заглушками, сборка падает, если credentials попали в
  артефакт, а CSP ограничивает соединения собственным origin.
- **Облачная синхронизация.** Стенд не пишет и не читает пользовательские данные.
- **Секреты.** В workflow стенда нет ни секретов, ни токенов, кроме
  автоматического `GITHUB_TOKEN` с минимальными правами.
- **Исходный код.** Репозиторий не хранит код приложения: workflow проверяет
  репозиторий источника по конкретному SHA.

## Правила безопасности

- Публикация выполняется **только вручную** (`workflow_dispatch`), **никогда** по
  push, по расписанию или по цепочке других workflow.
- Развёртывание проходит через защищённое окружение `github-pages` с обязательным
  одобрением ревьювера: без подтверждения человеком сайт не публикуется.
- Допускается только исходный SHA, принадлежащий ветке `test-deploy` источника
  (проверка предка), либо SHA из журнала публикаций.
- Права выдаются по заданиям: `pages: write` и `id-token: write` — только
  развёртыванию, `contents: write` — только заданиям записи артефактов и журнала.
- Production-сайт https://tmksdm.github.io/IronLog/ этим репозиторием не
  затрагивается; данные пользователя не изменяются.

## Журнал публикаций

Опубликованные сборки регистрируются в ветке `journal` (файл `published.json`).
Журнал append-only: прежние записи не изменяются, не удаляются и не
переставляются, новые добавляются только в конец. Проверка этого свойства
выполняется заданием журнала и падает закрыто при любом расхождении.

## Ограничения

- Адрес `ironlog-test.github.io` задан именем организации и не меняется.
- Сайт публичный: тестовые сборки видны всем.
